# CSS 3D Slider

A visually impressive 3D Image Slider that showcases the power of CSS3 transforms and perspective. This project creates a rotating carousel of images in a three-dimensional space.

## Features

- **3D Transform Effects**: Uses `rotateY` and `perspective` to create a realistic 3D cylinder effect.
- **Pure CSS Animation**: The rotation and layout are handled primarily through CSS, demonstrating efficient rendering without heavy JavaScript.
- **Responsive Design**: Adjusts to fit the viewport.
- **Interactive**: (If applicable based on typical implementations) Hover effects or controls to pause/navigate the slider.

## Tech Stack

- **HTML5**: Structure for the image container.
- **CSS3**: Advanced `transform-style: preserve-3d`, keyframe animations, and 3D positioning.

## Setup

1.  Open `index.html` in your web browser.
2.  Add your own images to the `images` folder to customize the slider.
