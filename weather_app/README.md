# Weather App

A modern, visually stunning Weather Application built with HTML, CSS, and JavaScript. This app features a premium "Glassmorphism" design and dynamic theming that changes the visual mood based on real-time weather conditions.

## Features

- **Real-Time Weather Data**: Fetches accurate weather information (Temperature, Humidity, Wind Speed) using the OpenWeatherMap API.
- **Dynamic Theming**: The application's background color palette shifts dynamically to match the weather (e.g., Warm Orange for Sun, Muted Grey for Clouds, Deep Blue for Rain).
- **Glassmorphism Design**: Features a sleek, frosted-glass user interface with modern typography (Outfit font) and smooth animations.
- **Responsive**: Fully optimized for different screen sizes.
- **Interactive**: Includes search functionality with "Enter" key support and error handling.

## specific Tech Stack

- **HTML5**: Semantic structure.
- **CSS3**: Custom variables, radial gradients, animations, and flexbox/grid layouts.
- **JavaScript (ES6+)**: Async/Await for API calls and dynamic DOM manipulation.
- **API**: OpenWeatherMap.

## Setup

1.  Clone the repository.
2.  Open `index.html` in your browser.
3.  (Optional) Replace the API key in `script.js` with your own OpenWeatherMap key if needed.
