# Text to Speech Converter

A web-based text-to-speech (TTS) application that converts written text into spoken words using the browser's built-in Web Speech API.

## Features

- **Voice Selection**: Choose from a variety of available system voices (accents, genders).
- **Adjustable Settings**: Control the **Rate** (speed), **Pitch**, and **Volume** of the speech.
- **Real-time Synthesis**: Instant conversion of text to audio.
- **User-Friendly Interface**: Simple text area and controls for easy operation.

## Tech Stack

- **JavaScript (Web Speech API)**: Utilizes the `SpeechSynthesis` interface for core functionality.
- **HTML5**: Structure for input forms and selectors.
- **CSS3**: Styling for a clean and accessible UI.

## Setup

1.  Open `index.html` in a modern web browser (Chrome, Firefox, Safari, Edge).
2.  Type text into the input box.
3.  Select a voice and adjust settings.
4.  Click "Speak" to hear the text!
